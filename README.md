# 福州城市空气质量时空插值分析与预警平台

> 《GIS开发与WebGIS应用》课程实习作品 · 2026 · 福建农林大学 空间信息与数字技术
> 单人全栈 · 指导教师：课程组

> ⚠️ **本仓库是 2026-09-19 的一次快照。** 此后在本地交付树上的修复与迭代
> （UI 重设计、误差序列归档、测试补齐）**未同步到这里**。以代码为准时请留意这一点。

基于开放气象数据与国控站实测的城市空气质量 WebGIS：时空插值 → 六级分级 → 预警 → 暴露评估。

## 功能

- **空气质量时空插值**：站点实测 → 网格化插值面，按污染物切换
- **六级分级与预警**：HJ 633-2012 口径（4 污染物各自限值），预警横幅取市域最差等级
- **30 天逐时历史**：**逐点**回放（选点看曲线 + 拖时间轴看该时刻），**不做历史面动画**
- **暴露评估**：学校 / 医院 POI × 当前污染面叠加，按等级过滤与计数
- **专题图层**：底图切换、路网、POI、洪水情景（漫游/测距/导出）
- **OGC API - Features** 最小合规服务（OGC 17-069r4）
- **三角色权限**：游客 / 用户 / 管理员，受限功能前置锁定态而非事后 401

## 技术栈

| 层 | 选型 |
|---|---|
| 后端 | FastAPI + PostgreSQL / PostGIS，分层 `core → services → api → main` |
| 前端 | 原生 JS + Leaflet + ECharts（`js/layers`、`js/pages`、`js/ui` 模块化） |
| 空间服务 | OGC API - Features |
| 部署 | Docker Compose |

## 运行

```bash
cd backend
pip install -r requirements.txt
cp .env.example .env      # 填数据库连接
uvicorn main:app --host 0.0.0.0 --port 8000
```

接口文档：`http://127.0.0.1:8000/docs`

## 边界与诚实说明

- 本平台由一套**内涝 / 洪水分析系统**演进而来，后端若干模块仍保留其命名与业务
  （如 `main.py` 的服务标题）。洪水功能作为「一阶段成果」保留在独立页签，
  与空气质量主叙事物理隔离。**这是演进痕迹，不是两个项目。**
- 历史回放只做**逐点**，不做历史面动画（后端无历史面插值端点）。
- 暴露评估的空间范围限于**金山片区** POI 库，插值面分辨率约 4 km/格，判定粒度受限。
- 插值面为**模型输出**，非官方监测结论。
