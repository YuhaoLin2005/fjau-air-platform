## 1. 诊断一句话

产品名是空气质量，界面仍是洪水系统：AQ 图层默认关闭、藏在第 5 个 checkbox（index.html:213），初始视野是洪水金山片区（app.js:49-53），5 个页签里 3 个是洪涝遗留（index.html:191-195），六级国标分级被图例压成四档（index.html:341-344），"预警/时空/分析"三个承诺在 UI 上均未兑现（横幅是内涝的，history 前端零消费）。

## 3. 色带与图例规范（单一来源 = 后端）

后端 `airquality.py` 已按六级下发色值（已核实源码），前端**镜像这六个值**，不发明新色：

| 等级 | 后端色值 | 浓度区间（PM2.5 口径，μg/m³） |
|---|---|---|
| 优 | `#2E7D52` | 0–35 |
| 良 | `#C9A227` | 35–75 |
| 轻度 | `#E67E22` | 75–115 |
| 中度 | `#C0392B` | 115–150 |
| 重度 | `#8E2A3C` | 150–250 |
| 严重 | `#5B1220` | 250+ |

- 图例六级全量展示 + 区间数值 + hover 一句话健康指引（国标指引文案，非自拟）。
- **限值表=前端镜像常量**（后端不下发限值，airquality.py:15-19 是唯一权威）：前端按污染物硬编码
  4 套 HJ 633 限值并逐值镜像（PM2.5: 35/75/115/150/250；PM10: 50/150/250/350/420；O₃: 160/200/300/400/800；
  NO₂: 100/200/700/1200/2340 μg/m³），实现时加一步与 airquality.py:15-19 逐值对照验证防漂移。
- 色盲安全：色带边界加深色描边（weight 0.6 不透明）；重度/严重档面内叠加半透明斜纹图案（SVG pattern）；每个 popup 同时给文字等级——颜色不再是唯一通道。
- 三处图例（图层树色板/右上 #legend/底部 #aqLegend）合并为**一个**动态图例组件。
- 主题：`data-theme="aq"`，tokens 层新增 `--aq-1..--aq-6` 令牌族 + 暖调中性 UI 色；洪水功能保留冷调令牌（flood 主题局部作用域），两带不混用。
- 裁决说明（对照任务书"绿→黄→橙→红→紫"表述）：六级色相走向与任务书一致，但重度/严重两档具体色值以**后端 LEVEL_COLOR 为准**（#8E2A3C/#5B1220，酒红/暗红而非纯紫）——镜像后端优先于任务书的示意描述，避免前后端两套色。
- 撞色修复：预警横幅改用文字+图标主导；洪水模块内绿/橙仅存在于「一阶段成果¹」上下文。
